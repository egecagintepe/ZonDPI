# Getting Support for ZonDPI

Thank you for using ZonDPI!

---

## Where to Ask for Help

### 1. Documentation & Troubleshooting First
Before opening an issue or asking for support, please check our documentation:
* [Troubleshooting Guide](docs/TROUBLESHOOTING.md) — solutions for common connection and driver problems.
* [Compatibility Guide](docs/COMPATIBILITY.md) — antivirus and third-party software notes.
* [Installation Guide](docs/INSTALL.md) — setup instructions and requirements.

### 2. GitHub Discussions (Community Q&A)
For questions, general troubleshooting, ISP-specific discussions, and feature ideas:
* **[Join GitHub Discussions](https://github.com/egecagintepe/ZonDPI/discussions)**
* Ask questions about router/modem configurations, DNS issues, or usage tips.

### 3. GitHub Issues (Bug Reports & Compatibility Issues)
If you have found a reproducible bug or a specific compatibility failure:
* **[Open a GitHub Issue](https://github.com/egecagintepe/ZonDPI/issues/new/choose)**
* Use the provided issue templates and include relevant CLI diagnostics output (`zondpi-cli.exe diag`).

---

## Maintainer Note

ZonDPI is an open-source, community-driven project maintained by volunteers. There is no commercial warranty, SLA, or 24/7 support guarantee. We appreciate thoughtful, detailed reports with diagnostics output that help improve the utility for everyone.
