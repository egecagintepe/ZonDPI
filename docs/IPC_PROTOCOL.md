# ZonDPI Named Pipe IPC Protocol Specification

Version: **1.0.0** (Protocol Version: `1`)  
Default Endpoint: `\\.\pipe\zondpi-service-ipc`

---

## 1. Framing & Transport Layer

ZonDPI uses Windows Named Pipes for local inter-process communication between the UI/CLI frontend and the background `zondpi-service` daemon.

### Frame Format
All messages are encoded in binary length-prefixed frames:
```
+--------------------------+----------------------------------------+
| Length (4 bytes, u32 LE) | Payload (UTF-8 JSON string, N bytes)   |
+--------------------------+----------------------------------------+
```

- **Length Prefix**: 32-bit unsigned integer in Little-Endian byte order representing the exact byte size of the JSON payload.
- **Maximum Frame Size**: `1,048,576 bytes` (1 MiB). Frames exceeding 1 MiB are rejected with `FrameTooLarge` error to prevent Denial-of-Service attacks.
- **Payload**: Standard UTF-8 encoded JSON object conforming to `IpcRequest` or `IpcResponse`.

---

## 2. Request Envelope

Every request sent to the service must follow this JSON schema:

```json
{
  "request_id": "c1f7a049-74d1-44eb-b66c-54a78c187f54",
  "protocol_version": 1,
  "command": { ... }
}
```

| Field | Type | Description |
| :--- | :--- | :--- |
| `request_id` | `string` | Unique UUID or correlation string generated by the client. |
| `protocol_version` | `u32` | Protocol version (currently `1`). Mismatched versions return `UnsupportedProtocolVersion`. |
| `command` | `object` | Polymorphic command object (tagged union). |

---

## 3. Response Envelope

Every response returned by the service conforms to:

```json
{
  "request_id": "c1f7a049-74d1-44eb-b66c-54a78c187f54",
  "success": true,
  "result": { ... },
  "error": null
}
```

On failure:
```json
{
  "request_id": "c1f7a049-74d1-44eb-b66c-54a78c187f54",
  "success": false,
  "result": null,
  "error": {
    "code": "PortInUse",
    "message": "Local port 1080 is already in use by another service",
    "details": "Configure a different port in profile or stop conflicting process"
  }
}
```

## 4. Supported Commands

### `Ping`
- **Request**: `{"Ping": null}`
- **Response**: `result: null`

### `GetVersion`
- **Request**: `{"GetVersion": null}`
- **Response Result**:
  ```json
  {
    "service_version": "0.1.0",
    "protocol_version": 1
  }
  ```

### `GetStatus`
- **Request**: `{"GetStatus": null}`
- **Response Result**:
  ```json
  {
    "version": "0.1.0",
    "uptime_seconds": 120,
    "service_state": "Running",
    "mode": "Manual (ByeDPI)",
    "active_engine": "ByeDPI",
    "requested_engine": "ByeDPI",
    "active_profile": "byedpi_kaspersky_mode",
    "engine_pid": 26784,
    "engine_uptime_seconds": 95,
    "health": {
      "is_healthy": true,
      "latency_ms": 2,
      "message": "ByeDPI SOCKS5 service confirmed active and responding on 127.0.0.1:1080"
    },
    "compatibility_recommendation": "GoodbyeDPI (Confidence: 95%)",
    "fallback_reason": null,
    "last_error": null
  }
  ```

### `GetRecommendation`
- **Request**: `{"GetRecommendation": null}`
- **Response Result**:
  ```json
  {
    "detected_security_products": ["Windows Defender"],
    "recommended_engine": "GoodbyeDPI",
    "rationale": "GoodbyeDPI verified healthy for system-wide packet evasion.",
    "compatibility_rating": "Confidence: 95%"
  }
  ```

### `ListProfiles`
- **Request**: `{"ListProfiles": null}`
- **Response Result**: Array of `ProfileSummaryDto` objects.

### `StartEngine`
- **Request**:
  ```json
  {
    "StartEngine": {
      "engine": "byedpi",
      "profile": "byedpi-kaspersky-mode"
    }
  }
  ```

### `StartAuto`
- **Request**:
  ```json
  {
    "StartAuto": {
      "profile": "turkey-default"
    }
  }
  ```

### `StopEngine`
- **Request**: `{"StopEngine": null}`

### `SwitchEngine`
- **Request**:
  ```json
  {
    "SwitchEngine": {
      "engine": "goodbye",
      "profile": "superonline-default"
    }
  }
  ```

### `GetRecentLogs`
- **Request**: `{"GetRecentLogs": {"lines": 50}}`
- **Response Result**: Array of `LogEntryDto` entries from the supervisor's in-memory ring buffer.

## 5. Structured Error Codes

| Error Code | Meaning |
| :--- | :--- |
| `UnsupportedProtocolVersion` | Client protocol version is incompatible with service. |
| `BadRequest` | JSON framing, schema, or argument validation failed. |
| `EngineStartFailed` | Process failed to spawn or crashed immediately. |
| `EngineHealthFailed` | Process started but failed TCP/WinDivert health check. |
| `EngineStopFailed` | Error stopping worker process. |
| `ProfileNotFound` | Requested profile does not exist or attempted path traversal. |
| `ProfileInvalid` | Profile JSON file is malformed. |
| `PortInUse` | Target SOCKS5 port is already bound by another application. |
| `InternalError` | Unhandled backend exception. |
